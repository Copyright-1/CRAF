The mod was made 100% by AI, just warning you — it’s up to you whether to use it.

### Description:
The mod changes the following in Cleanroom’s code:
  * Removes the OpenGL version check (but there is a lock on 4.2 in the code, so the wrapper must be able to handle some of its functions)
  * Fixes key presses on mobile devices; without it (at least on MojoLaucher), you couldn’t press symbol keys (digits are an exception)

### How builds?
```
./gradlew buildMod
```
